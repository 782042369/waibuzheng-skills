## 核心原则

### 智能合并

**核心问题**：这些记录是否可以合并为一条更简洁的表达？

**判断标准**：问自己3个问题

| 问题 | 回答"是" → 合并 |
|------|-----------------|
| 1. 同一功能模块？ | ✅ 合并 |
| 2. 相似工作内容？ | ✅ 合并 |
| 3. 关联性强的工作？ | ✅ 合并 |

**示例**：
```
❌ 未合并：
   - 完善施工任务功能，未传contract_id时自动选择EPC合同
   - 完善施工页面合同台账，无绑定时自动展示EPC合同

✅ 合并后：
   完善施工任务管理功能，提升业务处理能力
```

### 价值优先

**核心问题**：这项工作带来了什么价值？解决了什么问题？产生了什么影响？

**转换公式**：
```
技术实现 → 功能成果 → 业务价值
```

**示例**：
- "实现了Redis缓存" → "优化数据访问性能，提升系统响应速度"
- "修复登录bug" → "解决用户登录问题，提升系统稳定性"
- "新增导出功能" → "完善数据导出能力，提升工作效率"

### 成果导向

**强调完成的功能和解决的问题**，而不是技术实现细节。

**错误示范**：
- ❌ "使用Vue3重构了前端页面"
- ❌ "通过正则表达式实现数据校验"
- ❌ "配置了ESLint规则"

**正确示范**：
- ✅ "优化页面加载速度，提升用户体验"
- ✅ "完善数据录入验证，提升数据准确性"
- ✅ "规范代码质量，提升开发效率"

### 简洁明了

用领导能听懂的业务语言，避免技术术语。

**示例**：
- "API接口" → "网络请求"
- "前端页面" → "操作界面"
- "后端服务" → "系统处理中心"
- "数据库" → "数据存储"

## 一、价值表达模板

**适用场景**：新功能开发、功能完善

**模板**：
```
完善【功能名称】功能，【提升用户体验/工作效率/系统能力】

**示例**：
- 完善数据导出功能，提升工作效率
- 完善用户权限管理，提升系统安全性

**模板**：
```
解决【问题类型】问题，【提升系统稳定性/可用性/可靠性】

- 解决用户登录失败问题，提升系统稳定性

优化【性能指标】，【提升处理效率/响应速度/系统吞吐】

**示例**：

## 五、价值分级标准

### 高价值（必须保留）

**判断标准**：
- 直接影响用户使用
- 显著提升系统性能
- 解决关键业务问题

**示例**：
- ✅ 完善用户管理功能（直接影响用户）
- ✅ 优化系统响应速度（显著提升性能）
- ✅ 解决数据一致性问题（关键业务问题）
- ✅ 增强数据安全保护（重要安全问题）

### 中价值（优先保留）

**判断标准**：
- 改善用户体验
- 提升工作效率
- 完善系统能力

**示例**：
- ✅ 改进表格展示效果（改善体验）
- ✅ 完善数据导出功能（提升效率）
- ✅ 优化数据录入流程（完善能力）

### 低价值（可选保留）

**判断标准**：
- 内部优化
- 代码整理
- 工具配置

**示例**：
- ⚠️ 代码格式优化（可过滤）
- ⚠️ 文档内容更新（除非影响用户）
- ⚠️ 开发工具配置（显著影响才保留）

### 数量控制

**总条目**：15-20 条
**高价值**：≥60%
**中价值**：≤30%
**低价值**：≤10%

## 附录：智能识别规则

### 自动识别技术术语

**规则**：即使不在术语表中，AI也应自动识别并转换技术术语。

**识别方向**：
- **系统架构**：端/层/服务/系统 → 业务端表达
- **数据处理**：数据/信息/字段 → 数据表达
- **界面交互**：页面/界面/显示 → 界面表达
- **安全认证**：加密/Token/认证 → 安全保护
- **性能优化**：缓存/压缩/异步 → 性能提升
- **操作流程**：操作/处理/逻辑 → 流程表达

**自动转换原则**：
1. 如果是纯技术实现（如序列化、格式转换）→ 过滤
2. 如果是技术手段（如使用Redis）→ 转换为业务效果
3. 如果是技术改进（如优化CSS）→ 转换为体验提升

## 总结

**核心公式**：
```
Git提交记录 → 识别技术细节 → 过滤或转换为业务语言 → 智能合并 → 突出价值成果
```

**关键点**：
1. ✅ 价值优先：突出工作带来的业务价值
2. ✅ 成果导向：强调完成了什么，而不是怎么做
3. ✅ 简洁明了：用领导能听懂的业务语言
4. ✅ 智能合并：同一功能模块的条目合并为一条
5. ✅ 数量控制：15-20条，高价值≥60%
5. ✅ 智能识别：自动识别并过滤技术细节
6. ✅ 技术细节识别：自动识别并过滤技术细节

**最终目标**：让领导通过周报清晰了解技术团队的工作贡献和价值产出。
