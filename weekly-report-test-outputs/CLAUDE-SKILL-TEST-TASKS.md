# Weekly Report Generator - Claude Skill 测试任务清单

> 在 Claude 中使用 weekly-report-generator skill 执行的测试任务

---

## 📋 测试任务说明

每个测试任务都是一个完整的 weekly-report-generator skill 调用，包含：
- **项目路径**: 要测试的Git仓库（占位符，需要替换成实际路径）
- **时间范围**: 相对时间或绝对时间
- **模板**: 使用的周报模板
- **输出格式**: Markdown/PDF/Word
- **输出文件名**: 生成的文件名

### 占位符说明

在使用测试任务前，需要先替换以下占位符：

| 占位符 | 说明 | 示例 |
|--------|------|------|
| `项目1` | 单个项目路径 | `E:\work\myproject` |
| `项目2` | 第二个项目路径（多项目测试） | `E:\work\another-project` |
| `模板目录` | 模板文件所在目录 | `E:\work\weekly-report\templates` |

**如何替换占位符**:

1. **单项目测试**:
```
项目路径：项目1
```
替换成：
```
项目路径：E:\work\myproject
```

2. **多项目测试**:
```
项目路径：项目1, 项目2
```
替换成：
```
项目路径：E:\work\project1, E:\work\project2
```

3. **Word/PDF模板**:
```
参考模板：模板目录/demo.docx
```
替换成：
```
参考模板：E:\work\weekly-report\templates\demo.docx
```

## 🚀 快速开始

### 如何执行测试任务

1. **复制测试任务**: 从清单中复制一个测试任务
2. **粘贴到 Claude**: 直接粘贴到 Claude 对话框
3. **等待生成**: Claude 会自动执行 skill 并生成周报
4. **验证结果**: 检查生成的文件是否符合预期

### 示例

**步骤1**: 复制测试任务模板
```
使用 weekly-report-generator skill
项目路径：项目1
时间范围：上周
输出文件名：TEST-001.md
```

**步骤2**: 替换占位符为实际值
```
使用 weekly-report-generator skill
项目路径：E:\work\myproject
时间范围：上周
输出文件名：TEST-001.md
```

**步骤3**: 粘贴到Claude执行

**步骤4**: 等待生成周报并验证结果

## 🐛 常见问题

### Q1: Word 文件生成失败

**可能原因**:
- 未安装 pandoc
- 未指定参考模板

**解决方案**:
```
使用 weekly-report-generator skill
项目路径：项目1
时间范围：上周
输出格式：Word (.docx)
输出文件名：TEST-001.docx
参考模板：模板目录/demo.docx
```

### Q2: PDF 中文乱码

**可能原因**:
- 未安装中文字体
- pandoc 配置错误

**解决方案**:
在 Claude 中明确要求使用中文字体：
```
输出格式：PDF (.pdf)
字体：SimSun（宋体）
参考模板：模板目录/demo.pdf
```

### Q3: 多项目数据未聚合

**可能原因**:
- 项目路径格式错误
- 路径之间缺少逗号

**解决方案**:
```
项目路径：项目1, 项目2
```
注意：路径之间用**逗号和空格**分隔
